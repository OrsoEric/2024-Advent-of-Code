To solve Part 2, the goal is to find the largest joltage possible by turning on exactly twelve batteries within each bank. The joltage is formed by the digits of the selected batteries in their original order.
Approach

Generate Combinations: For each bank, generate all possible combinations of 12 batteries.
Calculate Joltage: For each combination, calculate the joltage by concatenating the digits of the selected batteries.
Find Maximum: Track the maximum joltage for each bank.
Sum Results: Sum the maximum joltages for all banks to get the total output joltage.
Solution Code




from typing import List
from itertools import combinations

def find_max_joltage_part2(i_bank: str) -> int:
    """
    Finds the maximum joltage possible from a bank of batteries by turning on exactly 12 batteries.

    Parameters:
    i_bank (str): A string representing a bank of batteries.

    Returns:
    int: The maximum joltage possible from the bank.
    """
    max_joltage = 0
    # Generate all possible combinations of 12 batteries
    for indices in combinations(range(len(i_bank)), 12):
        # Extract the digits at the selected indices
        selected_digits = [i_bank[i] for i in indices]
        # Sort the indices to maintain the original order
        selected_digits_sorted = [i_bank[i] for i in sorted(indices)]
        # Calculate the joltage
        current_joltage = int(''.join(selected_digits_sorted))
        if current_joltage > max_joltage:
            max_joltage = current_joltage
    return max_joltage

You're absolutely right—the brute-force approach using itertools.combinations is computationally expensive, especially for longer strings. For Part 2, we need to select 12 digits from a string of length n (where n is the length of the bank), and the brute-force approach has a time complexity of O(n choose 12), which is impractical for large n.

Optimized Approach
Key Insight:

The maximum joltage is obtained by selecting the largest possible digits in the leftmost positions (to maximize the value of the number formed).
We can use a greedy algorithm to select the largest digits while ensuring we pick exactly 12 digits.
Algorithm:

Iterate through the bank string and select the largest possible digits, ensuring we pick exactly 12 digits.
Skip smaller digits if we can still pick enough larger digits later.
Construct the number from the selected digits.

Optimized Solution Code




from typing import List

def find_max_joltage_part2_fast(i_bank: str) -> int:
    """
    Finds the maximum joltage possible from a bank of batteries by turning on exactly 12 batteries.
    Uses a greedy approach to select the largest possible digits.

    Parameters:
    i_bank (str): A string representing a bank of batteries.

    Returns:
    int: The maximum joltage possible from the bank.
    """
    n = len(i_bank)
    k = 12  # We need to select exactly 12 digits
    if k > n:
        raise ValueError("Cannot select more digits than available in the bank.")

    # We want to select the largest possible digits, in order, to maximize the number.
    # This is equivalent to finding the largest number with exactly k digits from the bank.
    # We can use a greedy approach: select the largest possible digits from left to right.

    # Convert the bank string to a list of characters for easier manipulation
    bank = list(i_bank)
    selected = []
    to_select = k

    for i in range(n):
        # We need to select 'to_select' more digits from the remaining bank
        remaining = n - i
        if to_select > remaining:
            raise ValueError("Not enough digits left to select.")

        # Find the largest digit in the next (remaining - to_select + 1) positions
        max_digit = bank[i]
        max_pos = i
        for j in range(i + 1, n - to_select + 1):
            if bank[j] > max_digit:
                max_digit = bank[j]
                max_pos = j

        # Add the selected digit to the result
        selected.append(bank[max_pos])
        # Remove the selected digit from the bank to avoid reuse
        bank.pop(max_pos)
        # Decrement the number of digits left to select
        to_select -= 1
        # Reset the loop to start from the current position
        i = max_pos - 1  # because the next iteration will increment i

    # The selected digits are in the correct order
    return int(''.join(selected))

def solve_puzzle_part2_fast(i_filename: str) -> int:
    """
    Solves the puzzle for part 2 by reading the input file and calculating the total output joltage.
    Uses the fast greedy algorithm.

    Parameters:
    i_filename (str): The name of the input file.

    Returns:
    int: The total output joltage.
    """
    with open(i_filename, 'r') as file:
        lines = file.readlines()
    total_joltage = 0
    for line in lines:
        line = line.strip()
        total_joltage += find_max_joltage_part2_fast(line)
    return total_joltage

# Example usage:

print(total_joltage_part2_example)

Explanation:

Greedy Selection: At each step, the algorithm selects the largest possible digit from the remaining digits, ensuring that there are enough digits left to complete the selection of 12 digits.
Efficiency: This approach runs in O(n * k) time, where n is the length of the bank and k is 12. This is a massive improvement over the brute-force O(n choose 12) approach.
Correctness: The greedy approach guarantees the maximum possible number because it always selects the largest possible digits from left to right.

The error occurs because the algorithm tries to access an index in the bank list that doesn't exist. This happens when the loop in find_max_joltage_part2_fast tries to look ahead more positions than are available in the list.
Root Cause

The loop for j in range(i + 1, n - to_select + 1) can exceed the list bounds if n - to_select + 1 is greater than n (the length of the list).
This happens when to_select is too large for the remaining digits.
Fix
We need to ensure that the loop only iterates over valid indices. The correct upper bound for the loop should be min(n, i + (n - to_select - (i + 1)) + 1), but a simpler and safer approach is to limit the loop to min(n, i + (remaining - to_select + 1)).
Let's fix the loop bounds and ensure the algorithm works for all cases:

    Parameters:
    i_bank (str): A string representing a bank of batteries.

    Returns:

def find_max_joltage_part2_fast(i_bank: str) -> int:
    """
    Finds the maximum joltage possible from a bank of batteries by turning on exactly 12 batteries.
    Uses a greedy approach to select the largest possible digits.

    Parameters:
    i_bank (str): A string representing a bank of batteries.

    Returns:
    int: The maximum joltage possible from the bank.
    """
    n = len(i_bank)
    k = 12  # We need to select exactly 12 digits
    if k > n:
        raise ValueError("Cannot select more digits than available in the bank.")

    bank = list(i_bank)
    selected = []
    to_select = k

    for i in range(n):
        if to_select == 0:
            break
        # Find the largest digit in the next (n - i - to_select + 1) positions
        max_digit = bank[i]
        max_pos = i
        # Ensure we don't go out of bounds
        for j in range(i, n - to_select + 1):
            if bank[j] > max_digit:
                max_digit = bank[j]
                max_pos = j

        # Add the selected digit to the result
        selected.append(bank[max_pos])
        # Remove the selected digit from the bank to avoid reuse
        bank.pop(max_pos)
        # Decrement the number of digits left to select
        to_select -= 1
        # Reset the loop to start from the current position
        i = max_pos - 1  # because the next iteration will increment i

    # The selected digits are in the correct order
    return int(''.join(selected))

The idea is to keep track of the best possible number up to each position, given how many digits you have left to pick.
Solution Code




def find_max_joltage_part2(i_bank: str) -> int:
    n = len(i_bank)
    k = 12
    # dp[i][j] = max number using j digits from first i digits
    dp = [[-1 for _ in range(k+1)] for __ in range(n+1)]
    dp[0][0] = 0

    for i in range(1, n+1):
        for j in range(0, k+1):
            if dp[i-1][j] != -1:
                # Option 1: skip the i-th digit
                if dp[i][j] < dp[i-1][j]:
                    dp[i][j] = dp[i-1][j]
                # Option 2: take the i-th digit
                if j < k and dp[i-1][j] != -1:
                    new_num = dp[i-1][j] * 10 + int(i_bank[i-1])
                    if new_num > dp[i][j+1]:
                        dp[i][j+1] = new_num
    return dp[n][k]

Explanation

dp[i][j] stores the maximum number formed by selecting j digits from the first i digits of the string.
For each digit, you can either skip it or include it (if you still need more digits).
The final answer is in dp[n][k].
